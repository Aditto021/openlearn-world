Let's make things light up! ⚡

Arduino is a tiny computer board. Connect a few wires the right way, and YOU can make lights blink, buttons beep, and motors spin! Every project below shows exactly which wire goes where — just like a real Arduino kit.

Hardware

What's actually on the board.

MicrocontrollerATmega328P
Clock speed16 MHz
Operating voltage5 V
Input voltage (VIN, recommended)7–12 V
Digital I/O pins14 (6 give PWM)
Analog input pins6 (A0–A5)
DC current per I/O pin20 mA recommended (40 mA absolute max)
Flash / SRAM / EEPROM32 KB / 2 KB / 1 KB
⚠ Safety rule #1: never draw more than 20 mA from a single I/O pin — a quick blink demo is fine, but for anything long-running, wire a small resistor in series with the LED to protect both the LED and the board. Never connect a pin directly to 5V or GND without a load — that's a short circuit and can damage the board.

Setup

Get your first sketch running.

  1. Install the Arduino IDE. Download the free official IDE from arduino.cc/en/software for Windows, macOS, or Linux.
  2. Plug in your Uno via USB. Windows/macOS install drivers automatically; on Linux you may need to add your user to the dialout group.
  3. Select your board. In the IDE: Tools → Board → Arduino Uno.
  4. Select your port. Tools → Port — pick the one that appears only while the Uno is plugged in.
  5. Upload Blink. Open File → Examples → 01.Basics → Blink, then click Upload (→). The onboard "L" LED near pin 13 should start blinking.

When it doesn't work

Troubleshooting checklist.

🔌

Nothing uploads

Wrong board/port selected, a bad USB cable (some are charge-only), or another program has the port open. Unplug/replug and reselect the port.

💡

LED doesn't light

LEDs are polarized — the longer leg (anode) goes toward the resistor/pin, the shorter leg (cathode) toward GND. Flip it if it's dark.

📟

Sensor reads garbage

Open Tools → Serial Monitor and match the baud rate to your Serial.begin() call — a mismatch prints noise.

🔥

Something got hot

Unplug immediately. This almost always means a short circuit (pin wired straight to GND) or a reversed power connection. Recheck against the diagram before reconnecting.
