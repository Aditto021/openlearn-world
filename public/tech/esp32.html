Arduino's Wi-Fi cousin! 📶

The ESP32 board can do everything Arduino can do — PLUS it can connect to the internet! One important rule to remember: ESP32 likes gentler power than Arduino, so we'll show you exactly how to keep it safe and happy.

Hardware

What's actually on the board.

ProcessorXtensa dual-core, up to 240 MHz
WirelessWi-Fi b/g/n (2.4GHz) + Bluetooth 4.2
Logic voltage3.3 V (not 5V tolerant)
USB/VIN input5 V
ADC2× 12-bit (0–4095), ADC1 + ADC2
True analog out (DAC)2× 8-bit (GPIO25, GPIO26)
Flash / SRAM4 MB (typical) / 520 KB
Reserved GPIOs6–11 (internal flash — never use)
⚠ The #1 ESP32 mistake: wiring a 5V sensor signal straight into a GPIO. Arduino pins tolerate that; ESP32 pins can be permanently damaged by it. If a module only outputs 5V logic, use a level shifter or a resistor voltage divider.

Setup

Get your board talking to the Arduino IDE.

  1. Install the Arduino IDE (same one used for Arduino boards) from arduino.cc/en/software, if you haven’t already.
  2. Add the ESP32 board package. File → Preferences, paste this into "Additional Board Manager URLs": https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  3. Install it. Tools → Board → Boards Manager, search "esp32", install the Espressif package.
  4. Select your board. Tools → Board → ESP32 Arduino → DOIT ESP32 DEVKIT V1 (or your exact model).
  5. Select your port and upload. Some boards need you to hold the BOOT button while uploading starts — if upload fails, try that.
