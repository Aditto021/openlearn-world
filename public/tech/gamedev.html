From idea to playable.

Every game, in any engine, runs on the same core loop. Learn the concept here first, in plain JavaScript you can read top to bottom — then it’ll make sense in whatever engine you pick.

The core idea

The game loop.

1. Input

Read keyboard/mouse/touch

2. Update

Move things, check collisions

3. Render

Draw the new frame

↻ Repeat

~60 times per second

That’s it. Unity, Godot, Unreal, and Roblox all wrap this exact loop in more tooling — the loop itself never changes.

Building blocks

Ideas every engine shares.

📦

Sprites & assets

2D images or 3D models that represent characters, items, and scenery — the visual building blocks of a scene.

💥

Collision detection

Math that checks whether two objects overlap — in the demo above, simple rectangle-vs-rectangle checks (AABB collision).

🎛️

State management

Tracking "menu", "playing", "paused", "game over" — and what input and rendering should do in each state.

🧠

Game design vs. dev

Design is deciding what’s fun (rules, pacing, difficulty); development is building it. Both matter — neither is optional.
