Script and publish.

Roblox Studio is a free desktop app — it can’t be embedded or controlled from a web page (no website can do that, honestly, including this one). What this page gives you instead: the real install link, real Luau code, and the real steps to publish.

Official install

Get Roblox Studio, free.

Download directly from Roblox — you’ll need a free Roblox account to save and publish.

Open create.roblox.com
How a place is organized

The Explorer hierarchy.

Everything in Roblox Studio lives in a tree, visible in the Explorer panel. Knowing where things go is most of learning the tool.

Luau basics

Real scripts you can paste in.

Luau is Roblox’s own fast dialect of Lua. Right-click a service in the Explorer → Insert Object → Script (or LocalScript) to add one.

Ship it

Publishing your first experience.

  1. Build something in the Workspace — even a single colored Part with a script counts for your first publish.
  2. File → Publish to Roblox. Sign in with your Roblox account if prompted.
  3. Fill in a name, description, and thumbnail. These are shown to anyone who finds your experience.
  4. Set access (Public or Private) in the experience’s configuration on the Roblox website.
  5. Playtest it live at the experience’s roblox.com page, or share the link directly.
